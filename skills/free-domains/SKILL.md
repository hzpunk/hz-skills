# Free Domains & Zero-Cost Infra (`/free-domains`)

Реестр бесплатных доменных имен, DNS-провайдеров и zero-cost хостинга для быстрого прототипирования и пет-проектов.

## Рекомендуемые бесплатные доменные зоны и DNS:
- **Бесплатные домены:** `*.is-a.dev`, `*.js.org`, `*.eu.org`, `*.pp.ua`
- **Бесплатный DNS & Edge WAF:** Cloudflare Free Tier (DNS, SSL, CDN, Turnstile)
- **Zero-Cost Static Hosting:** GitHub Pages, Cloudflare Pages, Vercel Hobby
