# AI Design System (`/ai-design-system`)

Система проектирования конверсионных страниц на основе принципов Elaya Design и поведенческой психологии.

## Формула 1-Offer (Один экран — одно решение):
1. **Hero Screen:**
   - Четкий заголовок: Кому + Результат + Без чего (без боли).
   - Подзаголовок: Как именно это работает (2 предложения).
   - Единственный CTA (главное целевое действие).
   - Социальное доказательство (лица клиентов, логотипы, цифры).
2. **Проблема и Контраст:** Состояние «До» (боль, потеря времени) против состояния «После» (легкость, результат).
3. **Механика решения:** 3 простых шага, снимающих когнитивную перегрузку.
4. **Интерактивный расчет ценности:** Калькулятор окупаемости / ROI.
5. **Финальный CTA:** Без лишних полей (только контакт для связи).
