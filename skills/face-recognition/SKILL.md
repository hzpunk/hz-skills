# Face Recognition SDK (`/face-recognition`)

Локальное биометрическое распознавание лиц, проверка живости (Liveness Detection) и защита от спуфинга без отправки биометрии в сторонние облака (152-ФЗ compliant).

## Ключевые возможности:
- **1:1 Verification:** Сравнение селфи с фото в паспорте/профиле.
- **1:N Identification:** Поиск лица по локальной базе векторов.
- **Liveness Detection:** Проверка моргания, мимики, определение экранных атак (пересъемка с монитора).
