# HZ UI Craft: Премиальный визуальный инженеринг и анти-слоп стандарт

Этот навык объединяет ведущие мировые практики продуктового и визуального дизайна в единый строгий стандарт для предотвращения шаблонных, скучных и неряшливых интерфейсов (AI Slop).

---

## 1. Четыре режима поверхностей (Impeccable Modes)

Перед проектированием любого экрана определите точный режим поверхности:

1. **Persuade (Убеждение — Лендинги, Промо, Цены):**
   - **Цель:** Привлечь внимание, вызвать доверие и довести до целевого действия.
   - **Характер:** Смелая типографика, кинематографичный скроллителлинг, реальные скриншоты продукта, выразительные акценты. Запрещены сухие унылые списки.
2. **Operate (Управление — Админки, Дашборды, SaaS-инструменты):**
   - **Цель:** Быстрое безошибочное выполнение рабочих задач.
   - **Характер:** Плотная верстка, высокая информативность, четкая иерархия, наглядные графики с первого дня (`hz-admin-charts`), модальные формы (`hz-forms-as-modals`).
3. **Read (Понимание — База знаний, Документация, Блог):**
   - **Цель:** Легкое усвоение сложной информации.
   - **Характер:** Оптимальная ширина текстовой колонки (60–75 символов), контрастная читабельная типографика, удобная навигация и оглавления.
4. **Experience (Погружение — Портфолио, Шоукейсы, 3D-просмотр):**
   - **Цель:** Эмоциональный восторг от созерцания продукта.
   - **Характер:** Интерфейс отступает на второй план; в центре — сам интерактивный артефакт (3D-модель, Canvas-секвенция, физическая анимация).

## 2. Жесткие запреты (Craft-Floor Bans)

Категорически запрещено:
- ❌ **Запрет на серую грязь:** Использовать блеклый светло-серый текст на карточках (`#9CA3AF` на светлом фоне), нарушающий WCAG AA (минимум контрастности 4.5:1). Вспомогательный текст не должен быть светлее `#5E5A54`.
- ❌ **Запрет на хардкод палитры:** Использовать жесткие Tailwind-классы (`bg-slate-950`, `bg-zinc-900`, `text-neutral-400`). Использовать **строго** системные токены: `bg-background`, `text-foreground`, `bg-card`, `text-muted-foreground`, `border-border`, `bg-primary`.
- ❌ **Запрет на 6-строчные заголовки:** Заголовки Hero-секций обязаны быть снайперскими и широкими (максимум 2–3 строки при ширине контейнера 900–1100px).
- ❌ **Запрет на однообразные 3-колоночные сетки иконок:** Не плодить одинаковые карточки «Иконка + Заголовок + 3 строки текста». Использовать асимметричные бенто-сетки (Bento Grid) с чередованием масштабов 2x1, 1x1, 1x2.
- ❌ **Запрет на фейковые плейсхолдеры:** Запрещен `Lorem Ipsum` и плейсхолдеры вроде «Скоро здесь будет график». Вставлять живые реалистичные данные и рабочие графики.

## 3. Философия Apple Fluid Interfaces (WWDC)

Интерфейс ощущается живым, когда он ведет себя как физический объект в реальном мире:

1. **Реакция на `pointerdown`, а не на `click`:**
   - Подсветка кнопки или карточки должна происходить мгновенно в момент касания пальцем или нажатия кнопки мыши (`active:scale-[0.98] transition-transform duration-100 ease-out`). Задержка отклика создает ощущение «деревянного» интерфейса.
2. **Физические пружины вместо линейных `ease`:**
   - Все перемещения, модальные окна, дропдауны и дроверы настраиваются через пружины (Spring Physics):
   ```ts
   // Framer Motion / Motion One эталонные пружины Apple:
   const appleSpring = {
     type: "spring",
     stiffness: 400,
     damping: 30,
     mass: 1,
   };
   ```
3. **Прерываемость (Interruptibility):**
   - Пользователь должен иметь возможность прервать любую анимацию на середине пути (например, начать закрывать шторку или модалку, пока она еще открывается) без рывков.
4. **Глубина и материалы (Translucency & Depth):**
   - Использование многослойных эффектов стекла: `backdrop-blur-md bg-background/80 border border-border/50 shadow-sm`. Тень должна быть мягкой и рассеянной (двойная тень: контактная + объемная).
