# Taste Design (`/taste-design`)

Стандарт премиального визуального вкуса интерфейсов (TasteSkill.dev). Устраняет шаблонный вид «типичного AI-лендинга».

## Инварианты вкуса:
1. **Шрифтовой контраст:** Широкий акцидентный заголовок (Editorial/Display) + строгий нейтральный гротеск для чтения (Inter, Geist, SF Pro).
2. **Асимметрия и воздух:** Сетка без скучных монотонных 3-колоночных карточек. Использование бэнто-сеток с доминирующим блоком.
3. **Живая физика:** Плавные пружинные анимации (spring mass: 1, stiffness: 100, damping: 15) вместо прямолинейного linear easing.
4. **Запрет на дешевые эффекты:** Никаких едких неоновых градиентов, радужного размытия и гигантских теней.
