# Mockoops Screens (`/mockoops-screens`)

Презентация интерфейсов в реалистичных 3D-мокапах устройств и браузерных фреймах (Mockoops).

## Использование:
- Обертывание скриншотов продукта в стильные браузерные рамки с кнопками управления окном (macOS/Safari style).
- Изометрические 3D-наклоны интерфейсов при скролле (CSS `transform: perspective(1000px) rotateX(10deg)`).
- Слайдеры «До / После» с интерактивной шторкой.
