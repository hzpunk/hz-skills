# Onlook Visual Editor (`/onlook-visual-editor`)

Визуальный редактор React и Next.js компонентов прямо в браузере (Onlook).

## Принцип работы:
- Дизайнер или разработчик кликает на элемент в браузере и меняет отступы, шрифты, цвета.
- Onlook автоматически записывает изменения в исходные `.tsx` файлы в виде Tailwind CSS классов.
- Двусторонняя синхронизация: код $\leftrightarrow$ визуал без потерь.
