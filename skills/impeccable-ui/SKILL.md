# Impeccable UI (`/impeccable-ui`)

Методология безупречного проектирования интерфейсов (Peter Bakaus, Impeccable).

## 4 Режима Интерфейса:
1. **Persuade (Лендинги):** Минимальное трение, 1 ясный оффер, доказательства ценности, мгновенный CTA.
2. **Operate (Дашборды/Админки):** Высокая плотность данных, горячие клавиши, табличные фильтры, быстрые модалки.
3. **Read (Документация/Блог):** Оптимальная длина строки (60–75 символов), комфортная контрастность, отсутствие визуального шума.
4. **Experience (Интерактивные продукты):** Иммерсивная графика, 60fps анимации, тактильный отклик.
