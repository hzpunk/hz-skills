# SecOps Toolkit (`/secops-toolkit`)

Набор инструментов наступательной безопасности, рекогносцировки (OSINT) и автоматизированного пентеста веб-приложений.

## Категории проверок:
1. **Reconnaissance:** Поиск поддоменов (subfinder, amass), сканирование открытых портов (nmap, masscan).
2. **Web Vulnerability:** Поиск инъекций (SQLi, XSS, SSRF, RCE) через Nuclei и Dalfox.
3. **Secrets Audit:** Поиск утекших API-токенов и приватных ключей через Gitleaks и Trufflehog.
4. **Cloud Security:** Проверка прав S3/R2 бакетов и конфигураций IAM.
