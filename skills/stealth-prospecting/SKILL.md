# HZ Stealth Prospecting & Sales Engine

Этот навык превращает AI-агента в автономного B2B-скаута и менеджера по продажам, способного управлять реальным веб-браузером, обходить анти-бот защиты (Cloudflare, Datadome), находить целевых клиентов и генерировать конверсионные предложения.

---

## 1. Два режима подключения к браузеру

### Режим А. Подключение к вашему живому Chrome (Рекомендуемый для личных продаж)
Вы запускаете свой основной Chrome с открытым портом отладки. Агент подключается к вашему браузеру через Chrome DevTools Protocol (CDP), используя ваши сохраненные авторизации (Telegram Web, почта, HeadHunter, VK, LinkedIn):

```bash
# macOS запуск Chrome с портом отладки:
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir="/tmp/chrome_dev_session"
```
- **Преимущество:** Сайты видят реальный пользовательский профиль. Нулевой риск блокировки.

### Режим Б. Автономный Stealth Browser MCP (`vibheksoni/stealth-browser-mcp`)
Фоновый headless-браузер на базе `nodriver` / `undetected-chromedriver` с подменой Canvas-отпечатков, WebGL-вендоров и маскировкой `navigator.webdriver = false`:
- **Преимущество:** Работает полностью в фоне без открытия окон, автоматически обходит Cloudflare Managed Challenges и собирает данные тысячами страниц.

## 2. Четырехэтапный конвейер B2B-продаж (Sales Sourcing Cycle)

```
┌─────────────────────────────────────────────────────────────┐
│                 B2B PROSPECTING CONVEYOR                    │
└─────────────────────────────────────────────────────────────┘
  1. Таргетинг сегмента (Отрасль, география, размер компании)
          ▼
  2. Stealth-сканирование каталогов (Яндекс Карты, 2ГИС, реестры)
          ▼
  3. Экспресс-аудит сайта клиента (Поиск болей: баги, нет 152-ФЗ, медленный UI)
          ▼
  4. Снайперский аутрич (Персонализированный оффер прямо ЛПРу)
```

### Этап 1. Сбор пула потенциальных клиентов (Lead Scraping)
1. Агент заходит в отраслевой каталог, справочник или карту (например, «Стоматологии Москвы», «Школы онлайн-образования», «Юридические бюро»).
2. В режиме Stealth извлекает:
   - Название компании.
   - URL сайта.
   - Телефон, Email, ссылки на соцсети (Telegram/VK).
   - ФИО руководителя / генерального директора (из реквизитов / оферты на сайте).

### Этап 2. Автономный аудит сайта клиента (Pain Point Forensics)
Перед отправкой любого предложения агент открывает сайт клиента и за 15 секунд выявляет конкретные слабые места:
- ❌ **Нарушение 152-ФЗ:** Отсутствует чекбокс согласия на обработку персданных в формах (штраф до 150 000 ₽).
- ❌ **Медленная скорость:** Задержка первого рендера (LCP > 3.5s), тяжелые неотжатые картинки.
- ❌ **Устаревший дизайн:** Шаблонный сайт без мобильной адаптации и скроллителлинга.
- ❌ **Дыры в безопасности:** Формы без анти-бот защиты (Turnstile), уязвимость к спаму.

### Этап 3. Генерация снайперского коммерческого предложения
Агент категорически НЕ пишет холодный спам («Здравствуйте, мы агентство...»). Он пишет снайперское адресное письмо от имени основателя:

```
Здравствуйте, [Имя руководителя / Руководитель отдела маркетинга]!

Обратил внимание на ваш сайт [domain.ru]. Вы делаете классный продукт, но заметил 2 критических момента, из-за которых теряются клиенты:
1. Форма записи не защищена от спам-ботов и нет обязательного согласия по 152-ФЗ (риск штрафа Роскомнадзора).
2. На мобильных устройствах первый экран грузится дольше 4 секунд — до 30% посетителей уходят до клика.

Мы в HZ Foundation пересобираем такие страницы на скоростной статический движок с кинематографичным скроллителлингом и авто-доставкой заявок прямо в Telegram. 

Собрал для вас короткий интерактивный демо-мокап, как это может выглядеть: [ссылка].
Готовы обсудить на 10-минутном созвоне на этой неделе?
```

### Этап 4. Фиксация в базе и передача в Telegram
Все найденные лиды с их статусом (`scouted` ➔ `audited` ➔ `contacted`) автоматически выгружаются в SQLite-базу и пингуют ваш Telegram через `hz-gateway`.
